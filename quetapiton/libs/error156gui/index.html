Pure C Version

Simplicidade em Win32

A error156gui é uma biblioteca header-only escrita em C puro. Ela abstrai a complexidade do Windows SDK, permitindo que você crie janelas e controles com poucas linhas de código, sem arquivos .cpp ou .obj externos.

Obter Biblioteca

O arquivo gerado é um .h único contendo toda a implementação.

Compilação

Para compilar um arquivo main.c usando esta biblioteca com MinGW/GCC:

gcc main.c -o app.exe -lgdi32 -luser32

Exemplo Prático

#include "error156gui.h"

void OnClick() {
    MessageBox(NULL, "Botão C clicado!", "Sucesso", MB_OK);
}

int main() {
    Error156GUI gui;
    if (Error156_Init(&gui, "Error156 Pure C", 500, 400)) {
        Error156_AddLabel(&gui, "Digite seu nome:", 20, 20, 200, 25);
        Error156_AddInput(&gui, "Campo de texto", 20, 50, 200, 30);
        Error156_AddButton(&gui, "Confirmar", 20, 100, 120, 40, OnClick);
        
        Error156_Run();
    }
    return 0;
}

Referência da API

Error156_Init(Error156GUI* gui, title, w, h)

Inicializa a estrutura principal e registra a classe da janela no Windows.

Error156_AddButton(gui, text, x, y, w, h, callback)

Cria um botão nativo. O callback deve ser uma função void f().

Error156_AddInput(gui, placeholder, x, y, w, h)

Cria um campo de entrada de texto (Edit Control).

Error156_AddLabel(gui, text, x, y, w, h)

Cria um texto estático na tela.
