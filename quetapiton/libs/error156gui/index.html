Documentação Oficial v1.0.0

A error156gui é uma biblioteca single-header ultra-leve para C++ que permite criar GUIs nativas no Windows sem a verbosidade da API Win32 tradicional.

Download da Biblioteca

Clique no botão abaixo para baixar a versão mais recente da error156gui.h.

Exemplo Rápido

#include "error156gui.h"

int main() {
    Error156GUI gui;
    if (gui.Init("Minha Janela", 400, 300)) {
        gui.AddButton("Sair", 125, 100, 150, 40, [](){ exit(0); });
        gui.Run();
    }
    return 0;
}

Referência da API

bool Init(const char* title, int w, int h)

Cria a janela principal e define o contexto da aplicação.

void AddButton(text, x, y, w, h, callback)

Adiciona um componente de botão clicável.
