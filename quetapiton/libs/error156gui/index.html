error156gui (Versão C Puro)

Uma biblioteca leve em C para criação de janelas Windows.

Exemplo de Uso (main.c)

#include "error156gui.h"

void acao() {
    MessageBox(NULL, "Clicado!", "Aviso", MB_OK);
}

int main() {
    Error156GUI gui;
    if (Error156_Init(&gui, "Minha App em C", 400, 300)) {
        Error156_AddButton(&gui, "Botão C", 100, 100, 120, 40, acao);
        Error156_Run();
    }
    return 0;
}

Como Compilar

Use o compilador GCC:

gcc main.c -o app.exe -lgdi32 -luser32
